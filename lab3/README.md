# Лабораторная работа №3
## Базовые растровые алгоритмы

### 1. Цель работы

Цель лабораторной работы — познакомиться с принципами построения графических объектов на растровом изображении и реализовать несколько алгоритмов, которые позволяют строить отрезки и окружности из отдельных пикселей.

В ходе работы были изучены пошаговый алгоритм, алгоритм цифрового дифференциального анализатора (ЦДА), алгоритм Брезенхема для построения отрезков и алгоритм Брезенхема для построения окружностей.

Также была создана программа с графическим интерфейсом, в которой можно выбирать алгоритм, задавать координаты и наблюдать за результатом его работы.

### 2. Теоретическая часть

#### 2.1. Что такое растровое изображение

Растровое изображение состоит из большого количества маленьких элементов — пикселей. Каждый пиксель имеет своё положение на координатной сетке и определённый цвет.

В отличие от векторной графики, где объекты описываются математическими линиями и фигурами, в растровой графике изображение формируется из отдельных точек.

Например, чтобы нарисовать наклонную линию, недостаточно просто провести обычную геометрическую прямую. Необходимо определить, какие именно пиксели нужно закрасить, чтобы линия выглядела максимально похоже на исходную.

Именно эту задачу решают растровые алгоритмы.

В программе каждому пикселю соответствует целочисленная координата `(x, y)`. Одна клетка координатной сетки соответствует одному пикселю. Все клетки имеют одинаковый размер, а выбранные алгоритмом клетки закрашиваются.

#### 2.2. Пошаговый алгоритм построения отрезка

Пошаговый алгоритм использует уравнение прямой и последовательно вычисляет координаты точек, которые нужно закрасить.

Для отрезка с началом `(x1, y1)` и концом `(x2, y2)` сначала вычисляются приращения:

- dx = x2 - x1;
- dy = y2 - y1.

Затем выбирается направление, в котором будет выполняться основной шаг. На каждом шаге вычисляется положение следующего пикселя.

Основная идея заключается в последовательном перемещении вдоль отрезка с вычислением второй координаты по уравнению прямой.

Недостаток такого подхода — необходимость выполнять вычисления с вещественными числами, а также возможные ошибки округления.

#### 2.3. Алгоритм ЦДА

ЦДА (цифровой дифференциальный анализатор) — алгоритм построения отрезка, который также использует последовательное вычисление координат.

Сначала определяется количество шагов:

steps = max(|dx|, |dy|).

Затем вычисляются приращения координат на каждом шаге:

- x_increment = dx / steps;
- y_increment = dy / steps.

Начальная точка постепенно смещается на эти приращения. Полученные координаты округляются до ближайших целых значений, после чего соответствующие пиксели закрашиваются.

Преимущество ЦДА — простота реализации. Однако алгоритм использует вещественную арифметику, поэтому накапливаются ошибки округления.

#### 2.4. Алгоритм Брезенхема для построения отрезка

Алгоритм Брезенхема позволяет строить отрезки с использованием преимущественно целочисленных вычислений.

Его основная идея — выбирать следующий пиксель на основе ошибки, которая показывает, насколько текущая растровая линия отклоняется от идеальной геометрической прямой.

На каждом шаге алгоритм анализирует значение ошибки и определяет, нужно ли изменить одну или обе координаты.

В отличие от ЦДА, алгоритм не требует постоянных вычислений с вещественными числами. Это делает его эффективным для растровой графики.

В реализованном варианте учитываются разные направления и наклоны отрезка, поэтому алгоритм может строить линии во всех октантах координатной плоскости.

#### 2.5. Алгоритм Брезенхема для построения окружности

Для построения окружности используется симметрия относительно её центра.

Если известна одна точка окружности в первом октанте, то по симметрии можно получить ещё семь точек.

Для окружности с центром `(xc, yc)` и радиусом `r` используются координаты восьми симметричных точек:

- `(xc + x, yc + y)`;
- `(xc - x, yc + y)`;
- `(xc + x, yc - y)`;
- `(xc - x, yc - y)`;
- `(xc + y, yc + x)`;
- `(xc - y, yc + x)`;
- `(xc + y, yc - x)`;
- `(xc - y, yc - x)`.

Алгоритм последовательно вычисляет точки одной части окружности, а остальные получает с помощью симметрии.

Для выбора следующего пикселя используется целочисленный параметр решения. Благодаря этому окружность строится без необходимости вычислять квадратный корень для каждой точки.

### 3. Практическая реализация

Для выполнения лабораторной работы был выбран язык программирования Python.

В качестве библиотеки для создания интерфейса использовалась Streamlit, а для отображения графики — Matplotlib.

Программа разделена на несколько частей:

- `app.py` — основной файл приложения, отвечающий за интерфейс и взаимодействие с пользователем;
- `algorithms/` — папка с реализациями четырёх растровых алгоритмов;
- `visualization/drawing.py` — файл, отвечающий за отображение пикселей на координатной сетке.

Такое разделение позволяет независимо изменять алгоритмы и способ отображения результата.

#### 3.1. Реализация алгоритмов

Каждый алгоритм оформлен в отдельном Python-файле.

На вход алгоритмы построения отрезков получают координаты начальной и конечной точек. Алгоритм окружности получает координаты центра и радиус.

Результатом работы каждого алгоритма становится набор координат пикселей, которые необходимо закрасить.

Таким образом, алгоритмы не занимаются непосредственно отображением графики. Они только определяют, какие пиксели должны быть задействованы.

Это позволяет использовать один и тот же способ визуализации для всех алгоритмов.

#### 3.2. Создание интерфейса

В основном файле `app.py` реализован интерфейс приложения.

Пользователь может выбрать один из четырёх алгоритмов:

1. Пошаговый алгоритм.
2. Алгоритм ЦДА.
3. Алгоритм Брезенхема для отрезка.
4. Алгоритм Брезенхема для окружности.

Для построения отрезка пользователь вводит координаты начальной и конечной точек.

Для построения окружности задаются координаты центра и радиус.

После изменения параметров изображение автоматически перестраивается, поэтому можно сразу наблюдать результат.

#### 3.3. Визуализация пикселей

Для отображения результата была реализована отдельная функция `draw_pixels()` в файле `visualization/drawing.py`.

Каждый пиксель изображается отдельным квадратом размером 1 × 1 в координатной системе.

Границы клеток совпадают с линиями координатной сетки. Благодаря этому можно наглядно увидеть, какие именно пиксели выбрал алгоритм.

Закрашенные пиксели выделяются синим цветом. Для окружности дополнительно отмечается её центр.

Также в приложении присутствуют координатные оси и подписи значений X и Y.

#### 3.4. Масштабирование изображения

В интерфейс добавлен ползунок масштаба.

Он позволяет приближать и отдалять изображение, изменяя видимую область координатной плоскости.

При увеличении масштаба пользователь может подробнее рассмотреть отдельные пиксели и оценить, как алгоритм формирует линию или окружность.

При этом координаты пикселей и результаты работы алгоритмов не изменяются — меняется только отображение.

### 4. Проверка работы программы

Для проверки корректности реализации можно использовать несколько примеров.

**Пример 1. Построение отрезка**

Начальная точка: `(1, 1)`.

Конечная точка: `(10, 6)`.

При построении этого отрезка каждый алгоритм должен сформировать последовательность пикселей, приближающуюся к заданной геометрической прямой.

Результаты разных алгоритмов могут немного отличаться из-за особенностей округления и выбора пикселей.

**Пример 2. Построение окружности**

Центр: `(0, 0)`.

Радиус: `5`.

При построении окружности должны появиться пиксели, расположенные симметрично относительно центра. Это позволяет проверить правильность использования симметрии в алгоритме Брезенхема.

Также была предусмотрена возможность менять входные координаты и масштаб, чтобы проверять работу программы на разных параметрах.

В результате выполнения лабораторной работы было создано приложение для демонстрации базовых растровых алгоритмов.

Реализованы:

- пошаговое построение отрезка;
- алгоритм ЦДА;
- алгоритм Брезенхема для построения отрезка;
- алгоритм Брезенхема для построения окружности;

Программа позволяет не только получать результат построения, но и наглядно изучать, как именно растровые алгоритмы выбирают отдельные пиксели.
